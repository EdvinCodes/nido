# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email **EdvinTrabajo@gmail.com** with:

- A description of the issue and potential impact
- Steps to reproduce
- Affected routes, tables, or components if known

We aim to acknowledge reports within 72 hours.

## Scope

In scope:

- Authentication and session handling
- Row Level Security bypasses
- Attachment storage and signed URL issues
- Server Actions and API routes that expose other users' financial data

Out of scope:

- Denial-of-service against a self-hosted instance you control
- Issues in third-party services (Supabase, Vercel, model providers)
- Social engineering

## Safe harbour

Good-faith security research that follows this policy will not be pursued legally.
Do not access data belonging to others without permission.
